# Nota

A beautiful, fast, and private notes app that works everywhere.

**Features:**
- Markdown with live preview
- Fully offline (PWA)
- Installable on phone, tablet & desktop
- Export / Import backup
- Dark mode by default
- No accounts, no tracking

Just open and write.
